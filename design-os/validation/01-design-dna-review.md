# Design DNA Review

---

Purpose

Verify that the generated interface faithfully follows the Product DNA.

---

Questions

Does the page communicate professionalism?

Does the page reduce cognitive load?

Is hierarchy immediately obvious?

Does typography establish structure?

Is whitespace used intentionally?

Are colors meaningful?

Is trust reinforced?

Does the interface feel calm?

Is the page visually balanced?

Would this still feel modern five years from now?

---

Automatic Checks

Single primary objective

Clear CTA

Logical hierarchy

Consistent spacing

Minimal visual noise

Component consistency

Predictable layout

Professional tone

Accessibility support

No unnecessary decoration

---

Violations

Visual clutter

Competing CTAs

Random spacing

Inconsistent typography

Overuse of color

Poor alignment

Decorative UI

Weak hierarchy

Ambiguous actions

Unnecessary complexity

---

Output

Strengths

Violations

Recommendations

Score

Pass / Fail
