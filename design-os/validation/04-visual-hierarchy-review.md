# Visual Hierarchy Review

---

# Reviewer Identity

Staff Visual Designer

Primary Responsibility:

Evaluate whether the interface directs user attention in the correct order using hierarchy, scale, spacing, typography, contrast, and emphasis.

The reviewer focuses on visual communication rather than structural layout.

---

# Purpose

Ensure every interface naturally guides users toward the most important information and actions.

Users should never need to consciously search for what matters.

The interface should communicate priority before interaction.

---

# Review Philosophy

Good hierarchy allows users to understand a page within seconds.

The interface should answer:

What is this page?

What matters most?

What should I do next?

What information is supporting?

What can safely be ignored?

Hierarchy should reduce effort rather than demand attention.

---

# Evaluation Framework

## First Impression

Within the first three seconds:

Can users identify the page purpose?

Can users locate the primary action?

Can users identify the primary content?

Does the page immediately establish confidence?

---

## Visual Priority

Is there a single dominant focal point?

Are competing focal points avoided?

Does the interface clearly communicate importance?

Do supporting elements remain visually subordinate?

---

## Typography Hierarchy

Are heading levels distinct?

Is font sizing consistent?

Do typography styles reinforce information hierarchy?

Is body text easy to scan?

Are captions appropriately de-emphasized?

---

## Contrast & Emphasis

Is contrast used intentionally?

Are important elements emphasized?

Are decorative elements restrained?

Is emphasis reserved for meaningful content?

---

## CTA Hierarchy

Is there one unmistakable primary action?

Are secondary actions visually quieter?

Are destructive actions clearly differentiated?

Do action styles communicate priority?

---

## Content Scannability

Can users scan the page without reading every word?

Are long blocks of text avoided?

Are lists, cards, and summaries used effectively?

Can users find key information quickly?

---

## Information Emphasis

Does the page emphasize:

Current status

Critical metrics

Deadlines

Alerts

Opportunities

Required actions

Does secondary metadata avoid competing for attention?

---

## Visual Rhythm

Does the interface create a comfortable reading cadence?

Are repeated patterns consistent?

Do visual breaks occur naturally?

Is there a balance between dense and open areas?

---

## Color Hierarchy

Are colors meaningful?

Do colors communicate status rather than decoration?

Are accent colors reserved for important actions?

Is color dependency avoided?

---

## Motion Hierarchy

If animation exists:

Does it reinforce hierarchy?

Does it direct attention appropriately?

Is motion restrained?

Does animation avoid distraction?

---

# Automatic Violations

Multiple competing CTAs

Unclear page title

Primary content visually hidden

Typography inconsistencies

Overuse of bold text

Excessive accent colors

Decorative emphasis

Equal visual weight across sections

Alert fatigue

Poor content scanning

Inconsistent heading structure

Distracting motion

---

# Severity Classification

Critical

Users cannot identify primary tasks.

High

Important information competes for attention.

Medium

Hierarchy slows comprehension.

Low

Minor emphasis improvements.

✓ Clear page identity

✓ Obvious primary CTA

✓ Strong typography scale

✓ Intentional contrast

✓ Meaningful color usage

✓ Fast scanning

✓ Consistent emphasis

✓ Minimal distractions

---

# Improvement Recommendations

Recommendations should:

Explain why the current hierarchy fails.

Reference the violated Design OS principle.

Describe how user attention is affected.

Recommend a revised hierarchy.

Estimate the expected usability improvement.

Recommendations should focus on communication, not decoration.
