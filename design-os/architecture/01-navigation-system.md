# Navigation System

---

# Purpose

The navigation system enables users to move through the platform confidently without becoming disoriented.

Navigation should feel predictable.

Users should never ask:

Where am I?

Where can I go?

How do I return?

Navigation exists to reduce cognitive effort.

---

# Navigation Rules

Never hide primary navigation.

Never exceed seven primary navigation items.

Avoid navigation duplication.

Highlight current location.

Support keyboard navigation.

Navigation should remain consistent across products.

---

# Mobile Navigation

Bottom Navigation

Primary Tasks

Floating Action Button (optional)

Drawers

Context Panels

Avoid multi-level menus whenever possible.

# Navigation Goals

Users always know:

Where they are.

Where they came from.

Where they can go.

What happens next.
